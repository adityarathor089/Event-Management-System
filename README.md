## Project description
CampusEvents is a beginner-friendly event management website for listing college events and recording participant registrations. It uses HTML, CSS and JavaScript. Data is stored in the browser using LocalStorage; no backend or database server is required.

## Features
- View event cards and dashboard counts.
- Add new events with date, venue and category.
- Register participants with name, email, 10-digit phone and event.
- Validate form fields and prevent duplicate registration for the same event.
- Search participant records.
- Delete participant registrations and events (events with registrations are protected).

## How to run
1. Extract the project folder.
2. Open `04_Website/index.html` in a modern browser (Chrome, Edge or Firefox).
3. Use **Add event** to create an event, then register participants.
4. Data remains in the same browser through LocalStorage.
